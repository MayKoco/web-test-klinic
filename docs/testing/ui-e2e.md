# Clinic UI — Manual E2E Test Flow

เอกสารนี้ใช้ไล่ทดสอบระบบผ่าน Browser ตั้งแต่ Login จนถึงการบันทึกข้อมูลจริงผ่าน API และ Database โดยไม่ผูกกับ test framework

## ข้อมูลตั้งต้น

- เปิด `clinic-test-web` และ `klinic-api` แล้ว
- ใช้ Database สำหรับทดสอบที่มี schema ล่าสุด
- มี Clinic และ Owner account ที่ Login ได้
- ตัวอย่างจาก seed: `CLINIC-0001`, `owner@test.clinic`, `Test1234!`
- ใช้ Database ทดสอบ เพราะ flow นี้สร้างข้อมูล Catalog จริง

## Flow 1 — Login เข้าคลินิก

1. เปิด `/login`
2. กรอก Clinic code, Email และ Password
3. กด `เข้าสู่สาขาที่เลือก`
4. รอ Dashboard โหลดเสร็จ แล้วตรวจชื่อ Clinic, Email และ Side menu
5. Refresh หน้าอีกครั้ง

**ผลที่คาดหวัง**

- Login สำเร็จและแสดงปุ่ม `ออกจากระบบ` ใน Side menu
- Refresh แล้วยังอยู่ใน session เดิม
- Clinic code ไม่ถูกเปลี่ยนตัวพิมพ์จน Login ผิด

## Flow 2 — เปิดหน้า Catalog

1. จาก Side menu กด `ผลิตภัณฑ์และบริการ`
2. รอรายการ Catalog โหลดเสร็จ
3. กด `โหลดใหม่`
4. ทดลองค้นหาด้วยชื่อหรือรหัสที่มีอยู่

**ผลที่คาดหวัง**

- เปิด `/catalog` ได้โดยไม่มี API error
- จำนวนใน Overview ตรงกับรายการที่แสดง
- กรองและค้นหารายการได้

## Flow 3 — ตรวจ Form ตามประเภทสินค้า

### 3.1 สินค้าทั่วไป

เลือก `สินค้า` และประเภท `สินค้าทั่วไป`

ต้องแสดงรหัส ชื่อ รายละเอียด ราคา หน่วย Barcode Stock ขั้นต่ำ Specification วิธีใช้ คำเตือน วิธีเก็บรักษา และตัวเลือก Lot/วันหมดอายุ

ต้องไม่แสดง field เฉพาะยาและเวชภัณฑ์ เช่น ชื่อสามัญทางยา วัสดุ และสถานะปลอดเชื้อ

### 3.2 ยา

เปลี่ยนประเภทเป็น `ยา` แล้วตรวจว่ามี:

- ชื่อสามัญทางยาและตัวยาสำคัญ
- ค่าความแรงและหน่วยความแรง
- รูปแบบยา สรรพคุณ ข้อห้ามใช้ และวิธีใช้
- ปริมาณ/หน่วยบรรจุและเลขทะเบียนยา
- คำเตือนและวิธีเก็บรักษา

ระบบต้องเปิด `ติดตาม Lot` และ `บังคับวันหมดอายุ` อัตโนมัติ พร้อมแจ้งว่าจะเป็น DRAFT จนกว่าจะรับ Lot แรก

### 3.3 เวชภัณฑ์

เปลี่ยนประเภทเป็น `เวชภัณฑ์` แล้วตรวจว่ามี:

- Specification วัสดุ และเลขทะเบียน/เลขอนุญาต
- วัตถุประสงค์การใช้งาน
- ปลอดเชื้อ: ไม่ระบุ / ใช่ / ไม่ใช่
- ใช้ครั้งเดียว: ไม่ระบุ / ใช่ / ไม่ใช่
- วิธีใช้ คำเตือน และวิธีเก็บรักษา

ต้องไม่แสดง field เฉพาะยา

## Flow 4 — สร้างสินค้าทั่วไป

| Field | Test data |
| --- | --- |
| รหัส | `UI-GEN-001` |
| ชื่อ | `UI Test General Product` |
| ราคา | `120` |
| Specification | `ขนาดมาตรฐาน 100 mL` |
| วิธีใช้ | `ใช้ภายนอก` |
| คำเตือน | `หลีกเลี่ยงดวงตา` |
| วิธีเก็บรักษา | `เก็บในที่แห้ง` |

1. กรอกข้อมูลตามตาราง
2. ไม่เลือกติดตาม Lot และเลือก `เปิดใช้งานทันที`
3. กด `สร้างสินค้า`
4. Reload หน้าและค้นหาด้วยรหัส

**ผลที่คาดหวัง:** แสดงข้อความสำเร็จ พบรายการหลัง Reload และสถานะเป็น `ACTIVE`

## Flow 5 — สร้างยา

| Field | Test data |
| --- | --- |
| รหัส | `UI-MED-001` |
| ชื่อ | `UI Test Medicine` |
| ราคา | `250` |
| ชื่อสามัญ/ตัวยาสำคัญ | `Paracetamol` |
| ความแรง | `500 mg` |
| รูปแบบยา | `เม็ด` |
| สรรพคุณ | `ลดไข้และบรรเทาอาการปวด` |
| วิธีใช้ | `รับประทานครั้งละ 1 เม็ดเมื่อมีอาการ` |
| ปริมาณบรรจุ | `10 เม็ด` |

1. เลือกประเภท `ยา` และกรอกข้อมูล
2. ตรวจว่า Lot และวันหมดอายุถูกเลือกอัตโนมัติ
3. กด `สร้างสินค้า`
4. Reload หน้าและค้นหาด้วยรหัส

**ผลที่คาดหวัง:** สถานะเป็น `DRAFT`, ระบบแจ้งให้รับ Lot แรก และข้อมูลยาไม่หายหลัง Reload

## Flow 6 — สร้างเวชภัณฑ์

| Field | Test data |
| --- | --- |
| รหัส | `UI-SUP-001` |
| ชื่อ | `UI Test Medical Supply` |
| ราคา | `80` |
| Specification | `หน้ากากทางการแพทย์ 3 ชั้น` |
| วัสดุ | `Non-woven polypropylene` |
| วัตถุประสงค์ | `ป้องกันละอองฝอย` |
| ปลอดเชื้อ | `ใช่` |
| ใช้ครั้งเดียว | `ไม่ใช่` |
| วิธีใช้ | `สวมให้คลุมจมูกและปาก` |

1. เลือกประเภท `เวชภัณฑ์` และกรอกข้อมูล
2. เลือกค่าปลอดเชื้อและใช้ครั้งเดียว
3. กด `สร้างสินค้า`
4. Reload หน้าและค้นหาด้วยรหัส

**ผลที่คาดหวัง:** สถานะเป็น `DRAFT`, ค่า boolean ยังตรงเดิม และ field ของยาไม่ถูกบันทึก

## Flow 7 — Validation และ Error handling

| กรณี | ผลที่คาดหวัง |
| --- | --- |
| ไม่กรอกรหัส ชื่อ หรือราคา | ไม่ให้ Submit และชี้ field ที่ขาด |
| ยาไม่กรอกสรรพคุณหรือวิธีใช้ | ไม่สามารถสร้างได้ |
| กรอกค่าความแรงแต่ไม่กรอกหน่วย | Backend ปฏิเสธและ UI แสดงข้อความที่เข้าใจได้ |
| กรอกปริมาณบรรจุแต่ไม่กรอกหน่วย | Backend ปฏิเสธและ UI แสดงข้อความที่เข้าใจได้ |
| ใช้รหัสซ้ำ | แสดง conflict และไม่เพิ่มรายการซ้ำ |
| API ปิดหรือ timeout | แสดง error และข้อมูลใน form ไม่ควรหาย |

## Flow 8 — Logout

1. กด `ออกจากระบบ` ใน Side menu
2. ทดลองเปิด `/catalog` อีกครั้ง

**ผลที่คาดหวัง:** Token และ profile ถูกลบ ไม่สามารถใช้ session เดิม และระบบแสดงหน้า Login
